# Серверная часть

Python 3.12, FastAPI, uvicorn и SQLite. Установка и локальный запуск описаны
в [основном README](../README.md). Команды ниже выполняются из папки `server`.

```text
python -m unittest discover -s tests
python -m sim.run 21 11
python -m sim.tune 21 12
```

`engine/` не требует сети. Время пересчитывается сеткой по 10 минут.
`engine/constants.py` содержит настройки потребностей, отношений и стадий речи.
`brain/` выбирает допустимые исходы и проверяет ответы моделей. Историческое имя
`ClaudeBrain` сохранено; транспорт может работать с OpenAI или Anthropic.
`app/wiring.py` собирает приложение из переменных окружения, `app/asgi.py` — точка входа.

## Хранилище и конфиденциальность

Папка `NEUROCRITTER_DATA` содержит `pet.sqlite`, журналы вызовов и бюджета,
ключ VAPID и другие данные конкретной установки. Не добавляйте её в Git.
Журналы вызовов могут включать память и реплики хозяина.
Тесты создают временные базы, а не используют живого питомца.

## Бюджет

`NEUROCRITTER_MONTHLY_LIMIT` задаёт месячный лимит учёта расходов приложения.
Цены зашиты в `brain/client.py`; при смене моделей сверяйте их с тарифами провайдера.
Это локальный учёт, а не ограничение счёта у провайдера. Настройте также его лимиты.
После достижения порога питомец использует запасные ответы.

## Web Push

Нужны HTTPS, поддержка браузера и разрешение на уведомления. Ритм вибрации
на часах определяется устройством. Тихие часы и частота настраиваются в PWA.
`NEUROCRITTER_VAPID_SUB` задаёт ваш контактный HTTPS-адрес для VAPID.

В режиме разработки доступна перемотка `POST /api/dev/advance`.
В рабочей установке `NEUROCRITTER_DEV` должен быть выключен.
