# Нейрозверёк «Недоделок»

Виртуальный питомец, который живёт в реальном времени, запоминает отношения с хозяином
и постепенно учится говорить. Образец НИИ ИИ КотоИмперии: корпус-картофелина,
ухо-антенна, три глаза, хвост непонятного происхождения и нечётное число лап.

Его надо кормить, мыть, развлекать, выводить гулять и давать отдыхать.
Он может отказаться играть, обидеться, приобрести привычки и внешне измениться от ухода.
Смерти нет: болезни и последствия заброшенности обратимы.

## Принцип

**LLM предлагает, движок решает.** Python-движок владеет объективным состоянием:
голодом, здоровьем, временем, отношениями и последствиями действий. Языковая модель
выбирает допустимый исход и озвучивает его. Ответ проверяется; при ошибке или
исчерпании бюджета используются запасные реплики. Питомец продолжает жить без API.

## Возможности

- Реальное время, автономный сон, потребности и характер, меняющийся от ухода.
- Растущая речь и постепенное освоение имени.
- Краткосрочная и долгосрочная память, ночной дневник, сны и режиссёр событий.
- Мутации, которые отражаются на рисунке питомца.
- PWA для компьютера и телефона: комната на canvas, шкалы, дневник и досье.
- Визуальные состояния и уведомления с вибрацией; звук для игры не требуется.
- OpenAI или Anthropic, учёт расходов, месячный лимит и режим без сети.
- Симулятор двух хозяев и автоматические тесты без вызовов платного API.

## Быстрый запуск

Нужен Python 3.12. Команды ниже для PowerShell, из корня проекта:

```powershell
cd server
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
$env:NEUROCRITTER_DEV = "1"
$env:NEUROCRITTER_BRAIN = "stub"
$env:NEUROCRITTER_DATA = "data"
.venv\Scripts\python -m uvicorn app.asgi:app --host 127.0.0.1 --port 8765
```

Откройте http://127.0.0.1:8765 и введите любой непустой токен. Затем вылупите питомца.
В режиме `stub` API-ключ не нужен и платных запросов нет. Установка зависимостей
требует интернета. Режим разработки предназначен для локального запуска.

Для Linux/macOS используйте `.venv/bin/python` и `export NAME=value` вместо
PowerShell-переменных. Настройка настоящего мозга — в [deploy/OPENAI.md](deploy/OPENAI.md).

## Проверки и симуляция

Из папки `server`:

```powershell
.venv\Scripts\python -m unittest discover -s tests
.venv\Scripts\python -m sim.run 21 11
```

Тесты используют подменные ответы и не отправляют данные провайдерам.
Скрипты `brain/demo*.py` и `tools/voice_test*.py` предназначены для отдельных проб:
режим `live` обращается к API и расходует средства. Проверьте выбранный провайдер
в конкретном скрипте перед запуском.

## Устройство

```text
client/         PWA: canvas, JavaScript, service worker
server/engine/  время, потребности, действия, характер, мутации, язык, память
server/brain/   транспорты API, промпты, валидация, бюджет, запись вызовов
server/app/     FastAPI, SQLite, авторизация, фоновые задачи, Web Push
server/sim/     симулятор ухода
server/tests/   тесты движка, памяти, API, уведомлений и провайдеров
```

Один сервер хранит одного питомца; несколько устройств открывают одно и то же состояние.
SQLite работает в режиме WAL. Память, тексты обращений, журналы и ключи относятся
к частным данным установки. Они не входят в эту копию.
При включённом LLM соответствующий контекст передаётся выбранному провайдеру.
